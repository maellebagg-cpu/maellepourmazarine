# maellepourmazarine.fr

Book de candidature alternance — Maëlle Baglin → Mazarine Digital.

Site statique HTML / CSS / JS (vanilla, sans framework). Hébergé sur Vercel.

## Pages

- `index.html` — accueil
- `a-propos.html` — bio + parcours
- `atelier.html` — outils + réalisations
- `etudes-de-cas.html` — étude de cas L'Heure Bleue sur le Nil
- `contact.html` — contact

## Dev local

Ouvrir n'importe quelle page dans le navigateur, ou servir le dossier
en HTTP avec :

```
python3 -m http.server 8000
```

puis aller sur `http://localhost:8000`.

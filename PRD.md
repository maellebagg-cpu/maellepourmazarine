## 🎯 Objectif du projet

Créer un site web multi-pages qui fait office de **lettre de motivation interactive et visuelle** adressée à **Mazarine Digital**, en réponse à leur offre d'alternance **Assistante Directeur Artistique**.

Le site est à la fois :
- Une **candidature ciblée et mémorable**
- Un **portfolio implicite** (le design du site démontre les compétences DA)
- Une **preuve de maîtrise web** (HTML/CSS/JS vanilla, multi-pages, dark/light mode propre)
- Le **conteneur des productions** (case study redesign, analyse critique, projet fictif Mazarine)

---

## 🧭 Direction stratégique — IMPORTANT

Le site **s'inspire** des codes Mazarine. Il **ne reproduit pas** mazarine.com.

**Ce qu'on emprunte à Mazarine (codes visuels) :**
- Esprit éditorial, contraste noir/blanc, accent crème/ivoire
- Typo serif élégante en titre (Playfair Display ici, en équivalent libre)
- Dark/light mode toggle (clin d'œil **revendiqué** dans le contenu)
- Grandes images, blanc tournant généreux, hiérarchie typographique forte

**Ce qu'on ne reproduit jamais :**
- Le code source, les images, les vidéos, les textes de mazarine.com
- Le logo, la signature, les marques du groupe
- Une page spécifique du site (sauf dans la section "Études de cas" → en *redesign*, donc en re-création explicite et créditée)

**Pourquoi cette ligne** : on candidate auprès de Mazarine. Leur envoyer un clone de leur site serait contre-productif (montre qu'on copie au lieu de créer) et juridiquement à risque. Un hommage stylistique assumé montre l'inverse : compréhension de leur langage + regard personnel.

## 🎨 Direction Artistique

### Palette

| Nom | Valeur | Usage |
|---|---|---|
| Noir | `#0a0a0a` | Fond dark mode, textes light |
| Blanc | `#f8f8f8` | Fond light mode, textes dark |
| Crème / Ivoire | `#e8dcc8` | Accent, highlights, hover |
| Gris foncé | `#1a1a1a` | Surfaces dark mode |
| Gris clair | `#e5e5e5` | Surfaces light mode |

### Typographie

| Usage | Police | Style |
|---|---|---|
| Titres H1 / hero | Playfair Display | Serif, bold, très grand |
| Titres H2 / H3 | Playfair Display | Serif, italic possible |
| Corps | Inter (ou DM Sans) | Sans-serif, fin |
| Labels / accents | Inter, uppercase, tracking large | Style magazine |

### Ambiance générale

- Éditorial, magazine de mode (registre Numéro / The Gentlewoman).
- Layouts asymétriques, grands blancs, textes superposés.
- Grands numéros de section (01, 02, 03…) en fond décoratif semi-transparent.
- Animations sobres : fade-in au scroll, slide-up, apparition lettre par lettre sur le hero.
- Pas d'animation gratuite. Chaque mouvement justifié.

### Dark / Light mode

- Toggle dans la navbar sur toutes les pages (icône lune/soleil).
- Transition CSS fluide (300ms).
- Préférence mémorisée en `localStorage`.
- **Défaut : dark mode** (plus impactant pour le registre luxe).

## ✅ Règles de qualité

1. **Aucun lorem ipsum** — tout le texte est réel et ciblé Mazarine.
2. **Aucun visuel reproduit** depuis mazarine.com (sauf en mode citation explicite et créditée dans la page Études de cas).
3. **Aucune image générique Unsplash** dans la page Univers — seulement compositions typographiques ou productions Maëlle.
4. **Responsive mobile-first**, breakpoints à 768px et 1200px.
5. **Performance** : pas de librairies inutiles, JS et CSS légers, images optimisées.
6. **Sémantique HTML** : `<nav>`, `<main>`, `<section>`, `<article>`, `<figure>`, `<footer>`.
7. **Accessibilité** : `alt` sur images, contrastes AA minimum, navigation clavier.
8. **Cohérence visuelle** : navbar, footer, tokens identiques sur toutes les pages.
